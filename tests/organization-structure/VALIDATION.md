- Run `node tests/organization-structure/open-para-counts.test.cjs`. It uses synthetic responses only. Covers counts, fit below 75%, manual overview zoom, 100%, focus, reset, panel restoration, stale count responses, preview invalidation, required reason, duplicate move suppression, form token, expected parent and selection after refresh.
- Build: `dotnet build AIS/AIS.csproj --no-restore`. During implementation an open Excel workbook (`wwwroot/Images/Page ID.xlsx`) blocked static asset fingerprinting. A temporary MSBuild target excluded workbook assets for the validation build, which passed with existing warnings. No project exclusions were committed.
- Server review: both move actions require the authenticated Super User session and page permission; the service repeats the role check. The POST validates anti-forgery. PP number comes only from the session. Preview releases its connection before confirmation. Move uses a single connection/transaction and named Oracle parameters, commits before cache invalidation, and attempts rollback on failure. Procedure validation messages are returned without the Oracle stack; busy locks request retry; unexpected errors are logged.
- The existing supplied package definitions are preserved, including mapping corrections and open-para aggregation. No database DDL runs at startup. The already compiled `T_ORG_ENTITY_MOVE_LOG` is required; its exact CREATE TABLE DDL was not supplied in the repository, so no replacement definition was invented.
- `OrganizationStructure:CacheSeconds` defaults to 15 (bounded to 1–15 seconds). A shared cancellation token immediately invalidates every scoped hierarchy cache entry in the application process after a committed move. A deployment with multiple worker processes requires shared invalidation between workers; local memory tokens do not cross process boundaries. Counts remain uncached. Explicit refresh bypasses the scoped hierarchy entry and then loads counts; client request generations discard obsolete responses.
- No production move was performed. Actual Oracle commit/rollback, lock contention, stale-parent rejection, and authenticated browser authorization should be exercised in a non-production environment with the compiled package and log table. Browser layout was checked through the focused DOM harness, not an authenticated live session.
